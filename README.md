# 🧠 Quiz Application

## 📌 Description
A dynamic quiz application with timer, multiple-choice questions, and score tracking.

## 🚀 Technologies Used
- HTML
- CSS
- JavaScript

## ✨ Features
- Timer-based questions
- Random question selection
- Instant answer feedback
- Score tracking system
- Restart quiz option

## 📂 Project Structure
- Quiz.html
- Quiz.css
- Quiz.js
